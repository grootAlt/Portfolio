# Shankar A R – Portfolio (React + Vite)

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # production build in /dist

- Edit all content in `src/data.js`.
- Resume PDF lives in `public/Shankar_Azhwar_Resume.pdf`.
- Skill logos load from the Devicon CDN; project logos from Google's favicon service (with letter fallbacks).
- Deploy `dist/` to Vercel, Netlify or GitHub Pages.
